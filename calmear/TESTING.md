# 検証結果

Flaskテストクライアントで以下を確認しました。

- 選択可能な音は12種類で、警報・サイレンの入力欄は存在しない。
- range・radio要素が存在せず、チェックボックスだけで選択できる。
- 提供ロゴPNGの配信が成功する。
- 追加選択欄は初期状態で折りたたまれ、既存の追加音が選択済みなら開く。
- チェック状態の保存・再表示、未選択時のkeep、内部強度50の固定。
- 改ざんされた警報設定の送信に影響されず、サーバーでprotect/0を保存する。
- 不正な音の拒否、CSRFチェック、13種類のパラメータ付き保存。
- DB障害時は503で操作を無効化し、内部エラー情報を画面に出さない。

DB呼び出しはモックです。実DB接続と実ブラウザーでの表示・操作は未検証です。ブラウザーから確認用ローカルサーバーへの接続がタイムアウトしました。
